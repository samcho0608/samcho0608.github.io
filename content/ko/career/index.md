이 섹션은 제 경력과 지원 자료를 블로그 안에서 바로 볼 수 있게 정리한 공간입니다.

저는 규모가 크고 운영 부담이 높은 시스템을 다루는 백엔드 엔지니어입니다. 핀테크와 대규모 커머스 환경에서 금융사 연동, 대출비교 서비스 정산 자동화, data serving, 운영 효율화 문제를 풀어왔고, 최근에는 high-availability read path와 조직 내 AI 활용 확산, internal tools 개발도 함께 맡고 있습니다.

## 현재 포지션

- 쿠팡 Interstellar Biz 팀에서 frontend service layer와 domain service layer 사이의 high-availability read path 개발
- backend domain의 high read traffic offloading 담당
- segment-based exposure, backend-driven UI orchestration 등 read 관련 cross-functional capability 개발
- Claude Code 기반 internal tools, plugin, consulting을 통한 AI 활용 확산
- operational complexity와 service coupling을 낮추는 backend architecture 설계
- 외부 연동과 비즈니스 핵심 flow의 Observability 강화

## 핵심 성과

- 70개 이상의 금융사 API를 하나의 내부 인터페이스로 추상화한 Gateway server 구축
- 80개 이상의 금융사 데이터를 처리하는 대출비교 서비스 정산 automation pipeline 설계 및 구축
- 대출 신청 flow의 server-side scraping infrastructure 운영 및 개선
- 외부 기관 연동 장애 대응을 위한 Observability와 automated reports 체계 구축
- Claude Code를 활용한 codebase 분석 사례와 팀 특화 tools 배포로 조직 productivity 개선

## 일하는 방식

제가 가장 잘하는 일은 운영상 비효율이 큰 문제를 발견하고, 그 문제를 system design 문제로 재정의한 뒤, 실제 운영까지 책임지는 방식으로 해결하는 것입니다. 이 방식은 대고객 backend systems뿐 아니라 internal productivity tools와 AI workflow를 만들 때도 동일하게 적용됩니다.
