# CLAUDE.md

This directory contains the main source content for the blog.

Important:
- keep this file language-neutral
- do not put English-only sentence-level rules here
- do not put Korean-only localization rules here
- use this file for content-wide writing defaults only

Content-wide defaults:
- prefer natural readability over rigid structure
- do not use headings unless they improve the piece
- do not make every post sound like a technical article
- do not make every post sound like a reflective essay either
- preserve the writer's judgment, personality, and restraint
- avoid generic AI-blog phrasing
- avoid corporate or content-marketing tone

Apply with:
- `/CLAUDE.md`
- `/.claude/style/blog-core.md`

Then add language-specific rules depending on the target language:
- English posts: `/.claude/style/english-blog-style.md`
- Korean localized posts under `content/ko/`: `/.claude/style/korean-blog-style.md` and `/content/ko/CLAUDE.md`
