# CLAUDE.md

This directory contains Korean localized content.

Important:
- do not inherit English sentence rhythm blindly
- do not translate mechanically
- localize into natural Korean prose
- preserve the original point, but rewrite for Korean readability
- it is acceptable to reorder paragraphs or change transitions if that makes the Korean version read naturally

Always apply:
- repository-wide rules from `/CLAUDE.md`
- content-wide rules from `/content/CLAUDE.md`
- shared principles from `/.claude/style/blog-core.md`
- Korean style rules from `/.claude/style/korean-blog-style.md`

Priority order:
1. preserve the core idea
2. make the Korean text sound natural
3. preserve the writer’s personality
4. keep the structure only if it still works in Korean

A Korean localized post should feel like an actually written Korean blog post, not a translation artifact.
